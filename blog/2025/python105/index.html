FAQ

Here are some good questions asked during class. The answers to these questions came from either some admin, TA, STA, or members of AIO2025.

Questions Answers
Are properties and attributes different in Python? No. Check out https://www.tutorialspoint.com
What-is-the-difference-between-attributes-and-properties-in-python https://www.uml-diagrams.org/class-diagrams-overview.html
Can I write 2 functions A and B where A calls B and B calls A? Why does it give an error when I refer to one before defining it? Yes. Such a situation is called mutual recursion. Python doesn’t execute function definitions which consist of function references. It only starts evaluating when a function is called.
A resource for mutable and immutable. https://www.geeksforgeeks.org/mutable-vs-immutable-objects-in-python/
A resource for pass by reference and pass by value https://www.tutorialspoint.com/python/python_functions.htm
How do I tell when two variables point to the same object in memory? You either need to understand what’s going on very well or check with the id() function. Each object has one and only one identity.
Can I use list comprehension to create a completely new list? Yes. It all depends on how you choose your values inside the branch condition.
Visualization for Sorted List https://www.cs.usfca.edu/~galles/visualization/Search.html
Are integral image and box filtering similar? Yes. Box filtering is in graphics.

copy() và deepcopy() là gì vậy ạ? Khi nào thì nên sử dung phương thức nào ạ? - Theo mình hiểu thì, copy() sẽ tạo một đối tượng mới ở cấp ngoài cùng, những sẽ dùng chung các phần tử bên trong với nhau. Còn deepcopy() sẽ tạo một đối tượng mới hoàn toàn và độc lập.
