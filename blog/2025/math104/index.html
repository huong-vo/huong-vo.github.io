Classification Problem Overview

A classification problem in machine learning involves training a model to learn patterns and predict outcomes based on specific input data. Outcomes or targets, often listed in a classifying column, is called a class, category, label, or ground truth. Ground truth is commonly used for image datasets. Input data, listed in other columns, is named a feature.

In the table above, there are three features including “Confident”, “Studied”, and “Sick”. Using them, we want to a model to provide some value of the class “Result”.

Review

Recall $A$ and $B$ are independent events if the occurence of A remains unaffected by that of B and vice versa, that is, $P(AB) = P(A) \cdot P(B) \text{ or } P(A | B) = P(A) \text{ or } P(B | A) = P(B)$. This concept significantly simplifies the process of working with large datasets since we only need to know the probability of events separately.

Events $A$ and $B$ are conditionally independent given $C$ if and only if

\[P(AB | C) = P(A | C) \cdot P(B | C) \text{ where } P(C) > 0.\]

Recall for a complete system $A_1, \cdots, A_n$ and an event $H$, Total Probability Theorem says

\[P(H) = P(H_1) + \cdots + P(H_n) = P(A_1) \cdot P(H | A_1) + \cdots + P(A_n) \cdot P(H | A_n).\]

The likelihood of Ai and that of H given Ai is true are included since the occurence of event H only makes sense when event Ai has happened. In classification problems, features only become meaningful to a training dataset within the context of the class. Without classes, models have no reference point to interpret what the features represent.

Bayes’ Rule says if $X$ is an event and $c$ is an element of a complete system ${C_1, \cdots, C_n}$ with $P(C_i) \neq 0$, then

\[P(C_i | X) = \frac{P(C_i) \cdot P(X | C_i)}{P(X)} = \frac{P(C_i) \cdot P(X | C_i)}{\sum_{i=1}^{n} P(C_j) \cdot P(X | C_j)}.\]

Note: The fact that such unrealistic assumptions are made gives right to the word naive in the Naive Bayes algorithm, which derives $P(AB) = P(A) \cdot P(B)$. For example, when we use this formula to classify emails with the word “Free Money”, it says P(Free Money) = P(Money Free) or “Free” is unrelated to “Money”, which is often not true. See practice exercises for detailed computations.

Multiple Features

For multiple-featured problems, apply Bayes’ Rule and conditional independence assumptions.

Let $C$ be a class and $X_1, \cdots, X_n$ be features (also known as random variables introduced in Math for AI 105 Warm-up). The formula for the probability of an event given a few other events has already occurred.

\[P(C | X_1, \cdots, X_n) = \frac{P(X_1, \cdots, X_n | C)P(C)}{P(X_1, \cdots, X_n)} = \frac{P(X_1 | C) \cdots P(X_n | C) \cdot P(C)}{\sum_{k} P(X_1, \cdots, X_n | C_k)}\]

where $C_k$’s are all labels.

Gaussian Function

All we’ve been through so far involves events where we can count the number of features. You may wonder, what if given datasets contain continuous values which lie within a given range instead of a finite set?

Definition

A distribution is a collection of data shared among a range of values on a variable.

The probability distribution for a random variable describes how the occurence of possible outcomes for an experiment are distributed over that variable. Its graph is bell-shaped, maybe skewed or not, as in figure. The Gaussian function is its special type known as normal distribution where its graph is symmetric bell-shaped curve as in figures.

\[f(x) = \frac{1}{\sigma \sqrt{2\pi}} \exp^{-\frac{(x-\mu)^2}{2\sigma^2}}\]

where

  • $-\infty < x < \infty$
  • $\mu_{X} = \frac{1}{n} \sum_{i=1}^{n} x_i$ is mean of the dataset $X$
  • $\sigma^2 = var(X) = \frac{1}{n} \sum_{i=1}^{n} (x_i - \mu)^2$ is the variance of the dataset $X$.

DEMONSTRATION

It’s worth pointing out a few fascinating properties of Gaussian distribution graph.

  • The graphs are symmetric bell-shaped curve.
  • Changing $\mu$ or $\sigma^2$ doesn’t change the bell shape of the normal distribution—it either shifts or stretches the standard graph (Figure ).
  • Any Gaussuan distribution can be converted to a standard normal distribution.
  • The area under the curve of the standard graph is $1$.

The third characteristic implies that we can use its area function as probability for continuous random variables with area being always non-negative and uninterrupted. For example, for the Iris flower case, the length and width can be any real number within some range. Thus using a function that can handle continuity like Gaussian would solve the problem.

Applications in AI
A Gaussian filter uses the Gaussian function to obtain a weighted avergae of surrounding pixels in Image Smoothing. A bilateral filter uses this concept with information of pixel color to perform better on edges of objects.

Central Limit Theorem is the idea of using a sample—a subset of the entire population—for analysis. You can take any example, but here we’ll use an image whose population contains pixel colors of the entire image. First, randomly select 30 pixels and compute their color mean. We repeat this process 10000 times. Eventually we can create a histogram of these averages. Even if the original values of the entire population are not normally distributed, the sample’s mean values are inclined to be.

Gaussian Naive Bayes Classifier (GNBC) for Continuous RV

Gaussian Naive Bayes is a machine learning algorithm that combines the Gaussian function and Bayes’ Theorem to solve continuous feature problems.

One Feature

The probability at one value $P(X | C) = 0$ at all times in the case of continuous random variables. So, if we use a real probability function, it’s impossible to make sense of a dataset. Instead, we want a different function that can capture the idea of likelihood. That function is called probability density function, which measures the density around a value. The higher the density is, the more likely the value is relative to others. As Gaussian area function acts as probability, the Gaussian function itself becomes such a density function.

\[P(X | C) = f(X | C) = \frac{1}{\sigma \sqrt{2\pi}} \exp^{-\frac{(X-\mu)^2}{2\sigma^2}}\]

where $\mu$ and $\sigma^2$ are the mean and variance class $C$.

Note: The density function can be evaluated greater than 1 when the graph narrows down and stretches. This is valid because the total area is still 1, which satisfies the probability concept all the probabilities are from 0 to 1.

FAQ

Here are some good questions asked during class. The answers to these questions came from either some admin, TA, STA, or members of AIO2025.

Questions Answers
Is dependence or independence better for AI? It doesn’t matter. AI can handle both.
Based on data, can I test if two features are dependent? Yes. You can use Chi-Square test of independence.
Why does nature generally have Gaussian distribution? Many variables in nature arise as the sum of many small and independent factors. According to the Central Limit Theorem, such variables tend to approximate a Gaussian distribution.
Diistinguish probability distribution and probability density functions. A probability distribution function applies to all random variables while a probability density function applies to continuous only.
