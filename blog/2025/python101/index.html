Data Representation

In Python, data can be represented in various ways which are sorted into three groups discussed below. To work with data in any programming language, we store it in a container called variable. That way, you can refer to and work with such a variable later on. In Python, the syntax to define a variable is simple.

variable_name = variable_value

You may think of variable name as the container’s name and a variable value as what the container holds. You are allowed to use and/or modify the value as needed.

mystery_box = "IPhone"

# a container called *mystery_box* has a value of *"IPhone"* in it.

What is a function?

DEMONSTRATION WITH BLENDER, INPUT, EXAMPLE

  • A function takes inputs, do something within itself, and returns outputs. There are situations where no inputs or outputs are fed to a function.
  • A function must start with the def keyword and is reccomended to end with the return keyword when defined. If none is expected to be returned, put return None.

Application in AI

Square Root Function $\sqrt{x}$ is used in Object Detection problems how much an object moves is relative its size and the function is to deal with this challenge.

Logarithm Function $\log({x})$ has $\log({1}) = 0$ and is a monotonically increasing function, i.e., $f(x_1) < f(x_2) \text{ when } x_1 < x_2$.

  • These properties extensively used in Optimization Algorithms problems which are ubiquitous in Machine Learning.
  • For example, in a situation where we maximize a function, evaluating its $\log$ is computationally easier than the function itself but does not change the maximum’s position.
  • $\log$ is used when you only care about how one number compares to another rather than their actual values. Since $\log$ of a number approaches $\infty$ and $-\infty$ much more slowly than the number goes to $\infty$ and $0$, respectively, the program can easily avoid the overflow and underflow issues.

DEMONSTRATION WITH PICTURE OF F(X) AND LOG(F(X))

Exponential Function $\exp({x})$ has a range of $(0, \infty)$ when $x$ is in $(-\infty, \infty)$.

  • This property allows $\exp({x})$ to be used in the Softmax Function. This function determines how related an object and its background in an image are.
  • For example, (positive relation) a rabbit and a bush or a snake and a bush have a postive relation; fish and a bush have a negative relation (you may convince me otherwise if you show me evidence where an alive fish is on land).

Design a Loss Function
In **Information Theory**, we aim to measure the *surprise* of an event. A more surprising event is less likely to happen, which interprets more information. $$Information(x) = \log({\frac{1}{p(x)}}) = -\log({p(x)})$$. Below is an descriptive example involving basic probability.
Problem statement: There are ten balls, nine reds and one blue, in a basket. If you pick up a ball from the basket, would getting a red or blue surprise you more?
Breakdown:
  • R and B are the events of getting a red and blue ball, respectively
  • E is the event of getting a ball
  • $p(E)$ is the probability of something happen or our believe
  • $s(E)$ is the level of surprise
  • $f(p)$ is the symbolic level of surprise
Idea: If $p(E)$ is higher, $s(E)$ and $f(p)$ are lower. This means $p(E)$ is disproportional to $s(E)$ and $f(p)$.
  1. We should first compute the probability of getting a ball.
    • $p(R) = \frac{9}{10} = 0.9$
    • $p(B) = 1 - p(R) = 0.1$
    This implies that the event of getting a red ball is more surprising whereas the opposite goes for getting a blue ball.
  2. Since $p(R) > p(B)$, we want $s(R) < s(B)$. There are two ways to build $s(E)$ satisfying this condition.
    • A linear function $s(E) = 1 - p(E)$
    • A non-linear function $s(E) = \frac{1}{p(E)}$
    Non-linearity has more interesting properties, so we choose it for $s(E)$.
  3. Have in mind that $p(E) \in [0, 1]$, so $s(E) = \frac{1}{p(E)} \in [1, \infty)$. This means $s(E) = 1$ shows no surprise, which is mathematically strange. It'd be more logical to have no surprise as $0$.
  4. We desire to achieve the level of surprise in $[0, \infty)$ instead. Note that two important properties of logarithm are
    • $\log({1}) = 0$: helps convert $1$ to $0$ as wanted
    • $\log$ is monotone: $f(p) = \log({s(E)}) = \log({\frac{1}{p(E)}}) = -\log({p(E)})$ is proportional to $s(E)$ as we need $f(p)$ also interprets the level of surprise.
  5. Computing $f(p)$ is more convenient that $s(E)$ since the graph of $\log$ approaches $\infty$ significantly more slowly than that of $s(E)$.
The solution is improved with steps 4 and 5, but it can be stopped at step 3.
Design the Softmax Function
We commonly use the Softmax Function in Machine Learning. For instance, given a picture, we want to measure how much the object and its background are related.
Problem statement: Given a list of data, what is the percentage of each data over their sum? Note that data can be positive, negative, and zero.
Breakdown:
  • $Z = \{z_1, \cdots, z_n\}$ where $z_i \in (-\infty, \infty)$
  • $S = \sum_{j=1}^{n} z_j = z_1 + \cdots + z_n$ is the sum of all data in $Z$
  • $p_i = f(z_i)$ is the probability of $z_i$ over $S$
Idea: For percentage/probability to make sense, we need to somehow create a non-negative number from negative $z_i$.
  1. Have in mind that $\exp({x}) \in (0, \infty)$ where $x \in (-\infty, \infty)$.
    • $Z = \{e^{z_1}, ..., e^{z_n}\}$ where $e^{z_i} > 0$ as wanted
    • $S = \sum_{j = 1}^{n} e^{z_j}$.
  2. $p_i = f(z_i) = \frac{e^{z_i}}{\sum_{j = 1}^{n} e^{z_j}}$ is the desired probability.
You can certainly use different bases, but $e$ is standard.

User-defined Functions

In addition to built-in functions, users are allowed to define a function for their own purpose.

  • A function is recommended to be defined at the beginning of the program.
  • A function is not executed until it is called.
  • A function is immediately canceled once its task is completed during the call.
  • A function does not necessarily have a return statement.
    • return statement gives some value once the call is finished.
    • return None is recommended if the function has no returned values.

You can think about a function in a program is like a room in a house. You go in when you need and go out once you’re done. If you need to take something out of the room, you need to have a container in hand to put it in and carry it out. Otherwise, you can walk in and out empty-handed.

Estimate the Area of a Unit Circle.
Problem statement: Approximate the area of a unit circle.
Breakdown:
  • $r = 1$ is the radius of the circle
  • $\alpha$ is the angle in degree starting at positive $x-axis$
  • $A_{est}$ is the estimated area of the circle
  • $A_{real}$ is the real area of the circle
Idea: We can break it into smaller equal-sized pieces in a way that we can approximate their area via some area formula. Thanks to the equality, we can scale up to get the estimated area of the circle.
  1. We first divide the circle into equal circular sectors:
    • Their angle for each sector is $\alpha$
    • The number of sectors is $n = \frac{360}{\alpha}$.
  2. Here we only know basic triangle area formulas, so we'll create triangles out of those sectors. There are two ways, either an isoceles or a right triangle.
    • An isoceles triangle: $A_{\alpha} = \frac{(r)(r) \sin({\alpha})}{2} = \frac{(1)(1) \sin({\alpha})}{2} = \frac{\sin({\alpha})}{2}$
    • A right triangle: $A_{\alpha} = \frac{height * base}{2} = \frac{\sin({\alpha}) \cos({\alpha})}{2}$.
  3. Those triangles roughly cover the circle, so their area sum is the estimated area of the circle.
    • Isoceles triangles: $A_{real} \approx A_{est} = n A_{\alpha} = \frac{360}{\alpha} \frac{\sin({\alpha})}{2}$
    • Right triangles: $A_{real} \approx A_{est} = n A_{\alpha} = \frac{360}{\alpha} \frac{\sin({\alpha}) \cos({\alpha})}{2}$
The lower the number of triangles is, the larger the gap between those triangles and the circle is and vice versa. In order to reduce the gap, we'll increase the number of triangles or decrease $\alpha$.

FAQ

Here are some good questions asked during class. The answers to these questions came from either some admin, TA, STA, or members of AIO2025.

Questions Answers
Does a program run the comments? No. The comments are only for the owners and readers.
What are real-life applications of a logarithm function? Information theory (entropy), Astronomy (lights’ and stars’ brightness), Machine learning (logistic regression, cross-entropy)
What are values modified for? Value modification is to avoid disadvantageous scenarios like overflow, underflow, slow computations, errors, divergent sequences. Some functions are used to change the range so that values are easier to be dealt with but still preserve core characteristics.
If one module needs a supporting one, do I need to import the latter? No. Modules consist of their supporting modules.

What is the difference between parameters and arguments? Parameters are like variables or placeholders while arguments are like values.
