Data Representation

In Python, data can be represented in various ways which are sorted into three groups discussed below. To work with data in any programming language, it is imperative that it be stored to a variable. That way, you can refer to and work with such a variable later on. In Python, the syntax to define a variable is simple.

variable_name = variable_value


Basically, you can think of a variable as a container, a variable name as the container’s name, and a variable value as what is inside that container. You may use and/or modify the value as needed. For instance, mystery_box = "IPhone"; here, a container called mystery_box has a value of "IPhone" in it.

Now, you may ask: What can I can name a variable? Is there any convention I should be aware of? A few thing is worth mentioning regarding this matter.

  • Meaningful name: Even though you can name a variable whatever you want, it makes sense to give a name relevant to its purpose.
