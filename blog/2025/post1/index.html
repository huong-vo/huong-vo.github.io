Created on June 11, 2025

2025   ·   random   journal

I finally finished my very first post for the course I’m taking, AIO2025, after 5 days of semi-hard work. Well, for more context, I set it up and wrote about one quarter of the whole post and stop for a couple of days before picking it up again today. It took me 4 days to clone this repository and set up the website (partially) with the help of my friend, J. (I don’t know if my friend wants to have the name public, so let me not do it). I’m behind on the lecture summarization and I’m far from having my website ready to the public. But, it’s okay; I’m just glad that I get one important thing done and want to briefly reward myself with avocado banana smoothie. I deliberately used half a banana as an alternative to sugar, condensed milk, or sweetened milk, but my smoothie turned out to be extremely sweet. I guess it’s for my tiny achievement.

I’ve learned a lot about using Markdown while making this first post. The whole writing process reminded me of the time I learned LaTex. You know, just jumping right in the battle field and googling ways to win it. It can be complicated, but I have not needed anything terribly challenging up to this point. Of course,there are stylings or decorations I hope to make so my blog does not look so dull. But what I have so far is acceptable for a complete newbie like me. I’ll learn more along the way and the journey will be much fun.

Let’s go back to what I learned:

A list for Markdown

  • Create internal and external links
  • Create a list
  • Create a table and incorporate CSS to style it
  • Use emojis

Initially, I didn’t think about using emojis at all, but I consulted this really cool post. There are a bunch of features here I want to incorporate into my posts. It will be a task for the future though.

A list for English

  • integrate and incorporate
  • efficient and effective

As a non-native English speaker, I always find it challenging using English in the most natural way. It takes a bit of time to look up words with similar meaning and then figure out which word is suitable for some situatuion. To avoid being stressed out while doing so, I try to think of it as an opportunity for me to improve not only writing skills but also translating ones. Soon I’ll get better at these skills.

Anyway, I think it’s time to be away from the screen for a bit and then start the second post.
