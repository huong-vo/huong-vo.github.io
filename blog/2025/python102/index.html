Suppose you want to draw a million stars. It’s take forever to complete this task unless you, I guess, desire to be a professional star drawer. There must be a way to avoid such an endlessly repetitive action. Exactly, it’s a loop, which repeats some action within itself. In Python, there are two types of loops including for and while loops.

For Loop

# code before for

for element in iterable:
    # code inside for

# code after for
  • A for loop is used when the number of times you want to iterate over a sequence (a.k.a, an iterable).
  • An iterable can be a string, list, dictionary, tuple, and range().
  • An element’s name can be almost anything but is usually i or _.

For now, we’ll focus on the range(start, stop, step) function.

  • start is $0$ and step is $1$ by default. Passing arguments to these parameters is optional.
  • The stop value is required.
  • The loop runs through range() from start up to but not including stop.

Let’s look at some examples.

range(3) range(1, 8, 3)
Logic flow
  1. range(3) starts at 0, ends by 3, and increases by 1:
    • 0 < 3 True -> add 1 to 0, get 1
    • 1 < 3 True -> add 1 to 1, get 2
    • 2 < 3 True -> add 1 to 2, get 3
    • 3 < 3 False -> stop
    So range(3) contains 0, 1, and 2.
  2. range(1, 8, 3) starts at 1, ends by 8, and increases by 3:
    • 1 < 8 True -> add 3 to 1, get 4
    • 4 < 8 True -> add 3 to 4, get 7
    • 7 < 8 True -> add 3 to 7, get 10
    • 10 < 8 False -> stop
    So range(1, 8, 3) contains 1, 4, and 7. 

# repeat 3 times
for i in range(3):
    print(i)
Logic flow
range(3) contains 0, 1, and 2.

  • i = 2 < 3 True -> print(2) -> add 1 to i = 2, get i = 3

While Loops

# code before while

while condition:
    # code inside while

# code after while
  • A while loop is used when you don’t know the number of iterations.
  • A while loop runs as long as conditions are fulfilled.

Always update the condition inside the loop. Or else, you may create/encounter an infinite loop which runs forever unless you force it to quit.


num= 1
a_list = [0, 1, 2]
while True == num in a_list:
    print("helloaivietnam")
    # remove the last time of a_list
    a_list.pop()
Logic flow
  • num = 1 in [0, 1, 2] True -> (True == True) True -> print("helloaivietnam") -> remove 2 -> a_list = [0, 1]
  • num = 1 in [0, 1] True -> (True == True) True -> print("helloaivietnam") -> remove 1 -> a_list = [0]
  • num = 1 in [0] False -> (False == True) False -> go out of loop -> display the rendered output
The rendered output is
helloaivietnam

Keywords Used in Loops

break

Imagine you are playing “Where’s Waldo?” and know exactly how many objects there are on the page. You want to look through images and stop the puzzle once you find Waldo. Or you could imagine you are playing a game where you have to guess a number. You’d have to keep guessing until you get the correct one; this is when the program would release you. Clearly, you need to use a loop to do iterations in each case, but you want a stronger command to leave when getting what you came for. Yup, it’s a break!

The break keyword is mainly used to terminate a loop regardless of whether a for loop iterates over the whole range or the condition in a while loop may still be satisfied. Simply put, when the program hits the break keyword, it breaks out of the loop.

continue

Imagine you are building a machine that would pick up only ripe strawberries and skip unripe ones without stopping. Here, a loop can handle part of the requirements and needs a magic word to fulfil what you expect. Such a magic word is continue.

The continue keyword is to skip the rest of the steps in this turn and move on with the next round. It is less common than the break keyword.

Examples and Exercises

Estimate the Area of a Unit Circle.
Problem statement: Approximate the area of a unit circle.
Breakdown:
  • $d = 1 - (-1) = 2$ is the diameter of the circle
  • $A_{est}$ is the estimated area of the circle
  • $A_{real}$ is the real area of the circle
  • $f(x) = \pm \sqrt{1 - x^2}$ are the functions of the upper-half and lower-half circles
Idea: Since the area of a circle is twice that of the upper-half circle, we can just focus on the latter. We can break it into smaller pieces in a way that we can compute their area via the function of a half circle.
  1. We first divide the upper-half circle into rectangles:
    • Their width is $\Delta{x_i}$
    • Their height is $f(x_i)$
    • The number of rectangles is $n = \frac{d}{\Delta{x_i}}$.
    The lower the number of rectangles is, the larger the gap between those rectangles and the circle is and vice versa. In order to reduce the gap, we'll increase the number of rectangles.
  2. Those rectangles roughly cover the half circle, so their area sum is the estimated area of the half circle.
    • $\frac{1}{2} A_{est} = \sum_{i = 1}^{n} f(x_i) \Delta{x_i}$
    • $A_{real} \approx 2 A_{est} = 2 \sum_{i = 1}^{n} f(x_i) \Delta{x_i}$.
This method is called Riemann Sum in Calculus and can be written as follows, $$A_real = \lim_{\Delta{x} \to 0} A_{est} = \lim_{\Delta{x} \to 0} \sum_{i = 1}^{n} f(x_i) \Delta{x_i}$$.

Questions Answers
Can I call a function before defining it? No. Python reads code top-down.
Can I write 2 functions A and B where A calls B and B calls A? Why does it give an error when I refer to one before defining it? Yes. Such a situation is called mutual recursion. Python doesn’t execute function definitions which consist of function references. It only starts evaluating when a function is called.
