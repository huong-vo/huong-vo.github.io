## **Data Representation**
In Python, data can be represented in various ways which are sorted into three groups discussed below. To work with data in any programming language, it is imperative that it be stored to a variable. That way, you can refer to and work with such a variable later on. In Python, the syntax to define a variable is simple.
```python
variable_name = variable_value
```
You may want to think of a variable as a container, a variable name as the container's name, and a variable value as what is inside that container. You are allowed to use and/or modify the value as needed. For instance,
```python
mystery_box = "IPhone"

# a container called *mystery_box* has a value of *"IPhone"* in it.
```

### **More Abstract Data Structures**
Just as their name suggest, primitive data representation can only support basic jobs. To handle more complex assignment, we need (built-in) multiplex structures such as list and dictionary. Here, we'll just get to know their definitions and discuss them in detai in future lectures.

#### **List**
```python
list_name = [element_1, ..., element_n]
```
In addition to their values, each element is associated to an **index** which is automatically created when the list is defined. Forward indices start at 0 for the first element on the left and increase one by one till the end of the list. In practice, you get to elements' values via their indices. #### **Dictionary**
```python
dictionary_name = {key_1: value_1, ..., key_n: value_n}
```
Another prevalent data structure is dictionary. When you look up a word in a regular-sense dictionary, you'll see two parts: the word and its meaning(s); no word appears more than once in a dictionary. A dictionary in Python is created in a similar fashion with unique keys and a value for each of them. Take the following example.
```python
# create a dictionary of a fruit's characteristics
fruit = {"name": "avocado", "type": "berry", "nutrition": ["fat", "fiber", "vitamins"], 7: 100}

fruit[7]
>>> 100
fruit["nutrition"]
>>> ["fat", "fiber", "vitamins"]
```
As seen above, in a dictionary, an element's value can be retrieved using its key in lieu of index.

### **Why do we need functions?**
~~DEMONSTRATION WITH A MAGIC BOX~~
Let's say you want a machine to make a sandwich every morning.

- It'd be time-consuming to place every single step in the machine every day just to make the same sandwich. You want it to receive one line of request and automatically undertake all the tasks. What can make this happen? Exactly, a function. It allows us to **reuse the same block of codes as wanted** without writing them all out.

- Possible steps to complete this job can be grouped into two main parts as in the table below. It's much clearer when **separating the tasks** because we know exactly how to allocate a set of actions to one block of time. Of course, you can certainly put all the actions in one function, but the readibility may drop drastically.

| Get the ingredients             | Put the ingredients together                                         |
|---------------------------------|----------------------------------------------------------------------|
| Get two slice of breads         | Use the knife to spread peanut butter on one side of a slice         |
| Get the peanut butter container | Use the knife to spread peanut butter on one side of the other slice | 
| Get a knife                     | Put the peanut butter sides of two slices together                   |

### **What is a function?**
~~DEMONSTRATION WITH BLENDER, INPUT, EXAMPLE~~

- A function takes inputs, do something within itself, and returns outputs. There are situations where no inputs or outputs are fed to a function. 
- A function **must start** with the `def` keyword and is reccomended to end with the `return` keyword when defined. If none is expected to be returned, put `return None`.
- A function's body **must be indented**. 
- A function is frequently named with a *verb* to indicate its action and written in **snake_case**.
- A function's parameters can be set to default values but passing different arguments to such parameters are allowed. Default values are often placed at the end of a parameter set.

### **Types of Functions**
There are two main types of functions including built-in functions and user-defined functions.

#### **Built-in Funtions**
Built-in functions are created by and freely available to the Python community. Two common built-in functions are `print` and `type`. The former displays output and the latter returns the type of a given variable. 

Besides functions used without further concerns, there are functions that can only be executed with packages called **module** like `random` and `math`. Use the `import` keyword to access modules. Try and see what the code below gives you. 
```python
import math

x = 4
y = -3

print(math.sqrt(x))
print(math.sqrt(y))
print(math.fabs(x))
print(math.fabs(y))
print(math.log(math.e))  # log is based e
```

#### :bulb: **Application in AI**
**Square Root Function $\sqrt{x}$** is used in **Object Detection** problems how much an object moves is relative its size and the function is to deal with this challenge.  

**Logarithm Function $\log({x})$** has $\log({1}) = 0$ and is a monotonically increasing function, i.e., $f(x_1) < f(x_2) \text{ when } x_1 < x_2$. 
- These properties extensively used in **Optimization Algorithms** problems which are ubiquitous in **Machine Learning**. 
- For example, in a situation where we maximize a function, evaluating its $\log$ is computationally easier than the function itself but does not change the maximum's position.
- $\log$ is used when you only care about how one number compares to another rather than their actual values. Since $\log$ of a number approaches $\infty$ and $-\infty$ much more slowly than the number goes to $\infty$ and $0$, respectively, the program can easily avoid the overflow and underflow issues.

**Exponential Function $\exp({x})$** has a range of $(0, \infty)$ when $x$ is in $(-\infty, \infty)$. 
- This property allows $\exp({x})$ to be used in the **Softmax Function**. This function determines how related an object and its background in an image are. 
- For example, (positive relation) a rabbit and a bush or a snake and a bush have a postive relation; fish and a bush have a negative relation (you may convince me otherwise if you show me evidence where an alive fish is on land).

## **Branching/Conditions**
Conditional statements in Python enables the execution of certain code blocks based on whether a condition is true or false. 

### **Comparison Operators**
Comparison operators are symbols used to compare two values and create a condition for a conditional statement. 

| Operator | Math   | Meaning               |
|:--------:|:------:|:---------------------:|
| $==$     | $=$    | Equal                 |
| $!=$     | $\neq$ | Not equal             |
| $>$      | $>$    | Greater than          |
| $<$      | $<$    | Less than             |
| $>=$     | $\geq$ | Greater than or equal |
| $<=$     | $\leq$ | Less than or equal    |
