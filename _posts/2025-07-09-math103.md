## **Basic Concepts**
**Probability** is a way to mathematicalize our real-life incidents. We'll first look at terminolgy used to talk about those incidents formally.

### **Defintions**
An **experiment** is a planned operation through which specific results are obtained. Some examples are flipping a coin and rolling a die. 
 
An **outcome** is a result of an experiment. If we put all possible outcomes together in a set, we call it the **sample space** denoted by $\Omega$ in this post. 
- *Possible outcomes* are displayed within braces $\\{\\}$.
- We can represent it in three following ways, which are demonstrated in later examples in this post,
    - **list** all possible outcomes
    - create a **Venn diagram**
    - create a **tree diagram**.

An **event** is a part/subset of the sample space, usually denoted by capital letters. It can be any combination of outcomes. There are three main types based on how likely an event is to happen.
- **Certain event:** an event that always occurs in an experiment, denoted by $\Omega$.
- **Impossible event:** an event that never occurs in an experiment, denoted by $\emptyset$.
- **Random event:** an even that may or may not occur in an experiment. An experiment whose outcomes are random events is called a **random experiment**.

We *mostly* work with random events and how to learn and hanlde their *randomness*. It's like the law exists to guide and regulate people's behavior, helping maintain order and fairness in society. Or analyzing stock prices is to identify the patterns, predict their future trends, and make informed investment decisions.

Let's take a look at some examples. Assume that the coin, die, and card deck are fair and regular.

| Experiment                   | Outcome        | Sample Space       | Event                                | Probability                   |  
|------------------------------|:--------------:|:------------------:|:------------------------------------:|:-----------------------------:|
| Flipping a coin              | {head}         | {head, tail}       | {tail}                               | $\frac{1}{2} = 0.5 = 50\%$    |
| Rolling a die                | {5}            | {1, 2, 3, 4, 5, 6} | {Die is odd} = {1, 3, 5}             | $\frac{3}{6} = 0.5 = 50\%$    |
| Picking a card out of a deck | {ace of heart} | a set of 52 cards  | {Card is a club} = a set of 13 clubs | $\frac{13}{52} = 0.25 = 25\%$ |

### **Types of Events**
When dealing with probability, we often encounter two common types of events which are distinguished concepts. We'll go over them all using events A and B above in a moment. 

**Mutually Exclusive Events** <br>

$A$ and $B$ are **mutually exclusive events** if they cannot both occur simulatenously, that is, they have no elements in common or $A \cap B = \emptyset$.  Otherwise, they are **non-mutally exclusive**. 

An example is events A and B from the practice exercise 1 above. Another example is training dataset and testing dataset in a *neural network*.

**Independent Events** <br>

$A$ and $B$ are **independent events** if the occurence of A remains unaffected by that of B and vice versa, that is, 

$$P(AB) = P(A) \cdot P(B).$$

$P$ represents the probability of an event which will be discussed in detail in the next section. The concept of dependent/independent events is commonly used to create a tree diagram for implication. This can help answer questions like if a treatment alleviates a disease or if there is a storm in the future with the current kind of weather. The *formula* derives from  **multiplication rule** mentioned in the next section, 

$$P(AB) = P(A) \cdot P(B | A).$$ 

Here, $P(B \| A) = P(B)$ since event A happening does nothing to the occurence of event B.

If A and B are not independent, then they are **dependent events**.

## **Probability**
As mentioned, probability is a way to mathematicalize concepts, managing events' randomness numerically. Using probability, we can talk about how likely an event occurs rather than making sets of elements. 

**Probability** is the likehood of an event happening. That is, when we conduct a large enough number of experiments, we observe the likelihood converges to some number---it is a probability.
- $0 \leq P(A) \leq 1$ where A is an event.
- $P(\Omega) = 1$: if P(A) is close to 1, then it's very likely that A occurs.
- $P(\emptyset) = 0$: if P(A) is close to 0, then it's very unlikely for A to occur.

{% include figure.liquid loading="eager" path="assets\aio2025\M02W02\tuesday_probability.png" class="img-fluid rounded z-depth-1 mx-auto d-block" zoomable=true max-width="450px" max-height="350px" alt="mathematical and real-life probability vocabulary" caption="" %} 

We approach different types of data in different ways in terms of probability computation. There are three primary methods to describe probability formula: *classical probability*, *geometric probability*, and *experimental probability*.

**Classical Probability** uses sets to perform a computation. We can use this method when sets are finite. Its formula is

$$P(A) = \frac{\text{number of favorable outcomes}}{\text{total number of possible outcomes}} = \frac{n(A)}{n(\Omega)}.$$

We'll use the same event A from the above example and have
- $\Omega = \\{ 1, 2, 3, 4, 5, 6 \\} \Rightarrow n_{\Omega} = 6$
- $A = \\{ 2, 4, 6 \\} \Rightarrow n_{A} = 3$
- $P(A) = \frac{n(A)}{n(\Omega)} = \frac{3}{6} = 0.5 = 50\%$.

**Geometric Probability**

For situations where sets are infinite, that is, we cannot count the number of elements, we'll use **geometric probability** to carry out calculations instead. It is applied in *Genetic Algorithm Optimization* or *Large Language Models (LLMs)* in *Machine Learning*. 

$$
P(A) = \frac{\text{measure of domain A}}{\text{measure of domain } \Omega} 
$$

where domain is the region an event can be. 

While *length* measures the region in 1D, *area* measures the region in 2D. We'll go over an example in one dimension. 

Let $x$ an arbitrary real number between 0 and 1 inclusively. What is the probability of $x$ between 0 and 0.25?
- $A = (0, 0.5) \Rightarrow \text{measure of domain A} = \text{length of segment } (0, 0.25) = 0.25$
- $\Omega = (0, 1) \Rightarrow \text{measure of domain } \Omega = \text{length of segment } (0, 1) = 1$
- $P(A) = \frac{\text{measure of domain A}}{\text{measure of domain } \Omega} = \frac{0.25}{1} = \frac{1}{4}$.

### **Rules of Probability**

**Addition Rule** refers to the probability of at least one event happening. It is known as **inclusion-exclusion principle**.
- Generally, we have

    $$P(A \text{ or } B) = P(A) + P(B) - P(A \text{ and } B)$$

    $$P(A \cup B) = P(A) + P(B) - p(A \cap B)$$ 

    $$P(A + B) = P(A) + P(B) - P(AB).$$

- If $A$ and $B$ are **mutually exclusive**---two events cannot occur simulatenously, then 

    $$P(A + B) = P(A) + P(B)$$

    since $P(AB) = 0$ by definition. 

- Since $A$ and $A^\prime$ are mutually exclusive, we can apply this rule and have the following

    $$P(A^\prime) = 1 - P(A) \text{ and } P(A) = 1 - P(A^\prime).$$

**Conditional Probability** is the probability that A occurs given that B has already happened or the probability of action A based on a condition B. As such, event B happens first then event A happens. Imagine if you want to know whether there might be a rainbow tomorrow afternoon, it helps to know if it rains before then. The conditional probability is denoted and formulated as follows. We'll discuss in detail the *second equality* in **Bayes' Rule**. 

$$P(A | B) = \frac{P(A \cap B)}{P(B)} = \frac{P(A)P(B | A)}{P(B)}$$

The *first equality* derives from probability definition. The condition "given B has already happened/a condition B" filters B in, saying that B is the new sample space. The condition "A occurs/action A" filters A in next, saying that from that sample space B, take only the ones from event A. The figure demonstrates this idea.

{% include figure.liquid loading="eager" path="assets\aio2025\M02W02\tuesday_venndiagram_conditionalprobability.png" class="img-fluid rounded z-depth-1 mx-auto d-block" zoomable=true max-width="250px" max-height="400px" alt="venn diagram of conditional probability with B light green and A intersecting B dark green" caption="<em>Figure 3.</em> Venn diagram of conditional probability with $A \cap B$ dark green" %} 

Let's solve an example using both the idea and formula. 

| Statement                       | Definition                                           | Formula                                                                 | 
|---------------------------------|:----------------------------------------------------:|:-----------------------------------------------------------------------:|
| A fair six-sided die is rolled  | $\Omega = \\{1, 2, 3, 4, 5, 6\\}$                    |                                                                         |
| A five is rolled                | $A = \\{3\\} \Rightarrow n(A) = 1$                   | $P(A) = \frac{1}{6}$                                                    |
| An odd number is rolled         | $B= \\{1, 3, 5\\} \Rightarrow n(B) = 3$              | $P(B) = \frac{3}{6}$                                                    |
| Given B then A                  | $n(AB) = 1$                                          | $P(AB) = \frac{1}{6}$                                                   |
| Probability                     | $P(A \| B) = \frac{n(AB)}{n(B)} = \frac{1}{3}$       | $P(A \| B) = \frac{P(A \cap B)}{P(B)} = \frac{\frac{1}{6}}{\frac{3}{6}} = \frac{1}{3}$ |

<br>

**Multiplication Rule** <br>
For two events, we have the following

$$P(AB) = P(A \cap B) = P(A) \cdot P(B | A) = P(B) \cdot P(A | B).$$

This formula is deduced from the conditional probability formula above,

$$P(A | B) = \frac{P(AB)}{P(B)} \text{   and   } P(B | A) = \frac{P(AB)}{P(A)}$$

\begin{align}
\label{conditional-multiplication}
    \Longrightarrow P(A) \cdot P(B | A) = P(AB) = P(B) \cdot P(A | B).
\end{align}

In general, if all $A_i's$ are true, we have the formula

$$P(A_1 A_2 \cdots A_n) = \underbrace{\underbrace{P(A_1) \cdot P(A_2 | A_1)}_{P(A_1 A_2)} \cdot P(A_3 | A_1 A_2)}_{P(A_1 A_2 A_3)} \cdots P(A_n | A_1 A_2 \cdots A_n).$$

:pushpin: **Pro tip:** If we divide a problem into separate braches and handle them in a *parallel* manner, use *additional rule*. If a problem is a *sequential* events, use *multiplication rule*.

## **Bayes' Theorem**

### **Total Probability Theorem**
:question: Using *conditional probability*, we can find the likelihood of an event happening provided that another event is true. Now **what if we want to find the probability of an event H and only know that several events have already occurred and they together make up the sample space?**

We can divide this problem into two stages including
- **Stage 1** (choose the path you want to go with): events A<sub>i</sub> are *pairwise mutually exclusive* and they combined are the sample space, which is called a **complete system**:
    - $A_i A_j = \emptyset$ $\forall i \neq j$
    - $\sum_{i=1}^{n} A_i = A_1 + \cdots + A_n = \Omega$
    - $P(A_1) + \cdots + P(A_n) = 1$.
- **Stage 2** (take action according to the path): event H happens given that each A<sub>i</sub> has already happened (each of them may or may not contain event H).

With this process and that all $A_i$ and $H_i = H \cap A_i$ happen separately, we'll be able to obtain the desired probability. The idea is to divide event H into smaller events and handle each of them individually. You can think of P(H\|A<sub>i</sub>) as variables, P(A<sub>i</sub>) as coefficients, and P(H) is the average with coefficients. The formula is as follows. 

$$P(H) = P(H_1) + \cdots + P(H_n) = P(A_1) \cdot P(H | A_1) + \cdots + P(A_n) \cdot P(H | A_n)$$

$$P(H) = \sum_{i=1}^{n} P(A_i) \cdot P(H | A_i)$$

### **Bayes' Rule** 
We can certainly pose another problem by reversing the situation from the *Total Probability Theorem* as follows.

:question: **Suppose that the probability of $H$ as a whole is known. What is the probability of $A_i$ given $H$ is true?**

Take the marble example in the practice exercise 1 above. We know the probability of each color, how do we figure out which bag has more red marbles in terms of percentage? Now the problem becomes a conditional probability: *What is the probability of picking a marble from bag 1/2/3 given that it is red?* 

Thus we can certainly use the result \eqref{conditional-multiplication} to obtain the following formula.

$$P(c | X) = \frac{P(X | c) \cdot P(c)}{P(X)}$$

where
- **Posterior** $P(c \| X)$ is the probability of c being true given X is true
- **Prior** $P(c)$ is the probability of c (before carying X)
- **Likelihood** $P(X \| c)$ is the probability of X being true given c is true
- **Marginalization** $P(X) \neq 0$ is the probability of X.

If $X$ is an event and $c$ is an element of a complete system ${C_1, \cdots, C_n}$ with $P(C_i) \neq 0$, then

$$P(C_i | X) = \frac{P(X | C_i) \cdot P(C_i)}{P(X)} = \frac{P(X | C_i) \cdot P(C_i)}{\sum_{i=1}^{n} P(C_j) \cdot P(X | C_j)}.$$
