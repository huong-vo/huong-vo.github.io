## **Measure of Central Tendency**
### **Mean and Expected Value**
Expected value is not considered a measure of central tendency, but this concept and mean are closely related as they both represent some sort of average. 

<table class = "language-python">
    <tr>
        <th>Mean</th>
        <th>Expected Value</th>
    </tr>
    <tr>
        <td colspan = "2" class = "centered_td">
        Given a dataset of N items $X = \\{X_1, \cdots, X_N\\}$
        </td>
    </tr>
    <tr>
        <td>
            $$\mu_{X} = \frac{1}{N} \sum_{i=1}^{N} X_i$$
            where $X_i$ is a specific outcome.
        </td>
        <td>
            $$E(X) = \sum_{i=1}^{N} X_i P(X = X_i)$$
            where $X_i$ is a specific outcome and $P(X = X_i)$ is the probability of a specific outcome. 
        </td>
    </tr>
    <tr>
        <td>
            <ul>
                <li> the <strong>average</strong> of all values in the dataset </li>
                <li> we've <strong>already collected</strong> all raw data </li>
                <li> Example: Consider playing a guessing game 100 times (in the detailed example below). We can only compute the mean once we've already played 100 times. </li>
            </ul>
        </td>
        <td>
            <ul>
                <li> the <strong>weighted average</strong> of all values in the dataset </li>
                <li> this value is what we expect to occur <strong>before collecting data</strong> </li>
                <li> Example: Consider playing a guessing game 100 times (in the detailed example below). We have either played it just a few times or never played it before but have some statistics on it. We can use such given data to predict what we may end up. </li>
            </ul>
        </td>
    </tr>

            <li> The money you'll lose/gain if you randomly select a student in AIO2025 and it turns out they do not love Math. </li>
        </ul> 
        <strong>Idea:</strong> With this information, we can analyze the likelihood of outcomes for the two student groups and evaluate whether this game works in your favor.
        <ol>
            <li> Compute the money gain/loss after playing 100 times for each case and the whole data. 
            <table class = "language-python">
                <tr>
                    <th></th>
                    <th>Love Math</th>
                    <th>Not Love Math</th>

                </tr>
                <tr>

                    <td class = "centered_td">$+\$1$</td>

                </tr>
                <tr>
                    <td>Expected number gains/losses</td>
                    <td class = "centered_td">$100 \cdot 0.3 = 30$</td>
                    <td class = "centered_td">$100 \cdot 0.7 = 70$</td>
                    <td class = "centered_td"></td>
                </tr>
                <tr>
                    <td>Expected gain (a negative number is a loss)</td>
                    <td class = "centered_td">$30 \cdot -1 = -30$</td>

            After playing this game 100 times in a roll, you would expect to gain \$40 in total.

### **Median**
Given a dataset of N items $X = \\{X_1, \cdots, X_N\\}$, median is the value dividing the sorted dataset in half. To obtain the median, we follow two steps. 
1. Sort $X$.
2. Calculate the median $m$:
    - If $N$ is odd, then $m = X_{\frac{N + 1}{2}}$.
    - If $N$ is even, then $m = \frac{X_{\frac{N}{2}} + X_{\frac{N + 1}{2}}}{2}$.

## **Measure of Variability**
### **Variance and Standard Deviation** 
<table class = "language-python">
    <tr>
        <th>Mean/Expected Value</th>
        <th>Variance</th>
        <th>Standard Deviation</th>
    </tr>
    <tr>
        <td></td>
        <td colspan = "2" class = "centered_td">
        measure <strong>how spread out</strong> data in a given set are from its mean/expected value
        </td>
    </tr>
    <tr>
        <td>$$\mu_{X} = \frac{1}{N} \sum_{i=1}^{N} X_i$$</td>
        <td>$$\sigma^2 = var(X) = \frac{1}{N} \sum_{i=1}^{N} (X_i - \mu)^2$$</td>
        <td>$$\sigma = \sqrt{var(X)}$$</td> 
    </tr>
    <tr>
        <td>$E(X) = \sum_{i=1}^{N} X_i P(X = X_i)$</td>
        <td>
        $$
        \begin{align*}
            \sigma^2 & = var(X) \\
                     & = E[(X - E[X])^2] \\
                     & = E[X^2] - (E[X])^2
        \end{align*}
        $$
        </td>
        <td>$$\sigma = \sqrt{var(X)}$$</td>
    </tr>
    <tr>
        <td><strong>Definition and Properties</strong></td>
        <td>
            <ul>
                <li> the average of squared differences from the mean/expected value </li>
                <li> squared distance between data points and the mean/expected value </li>
                <li> measured in squared units </li>
            </ul>
        </td>
        <td>
            <ul>
                <li> the square root of the variance </li>
                <li> typical distance between data points and the mean/expected value </li>
                <li> measured in a unit similar to the mean/expected value's unit </li>
            </ul>
        </td>
    </tr>
</table>
