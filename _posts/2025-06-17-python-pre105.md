## :mag_right: **OOP** 

"bring" the real world into digital world, meaning abstractinng real-world concepts and problems into a digital representation that a computer can process. 


4 OOP Characteristics (Tính chất):
- Encapsulation (Bao đóng)
- Inheritance (Kế thừa)
- Polymorphism (Đa hình)
- Abstraction (Trừu tượng)

What did we have before OOP was invented? It was **procedural programming** where we needed to arrange in order that, for example, functions can be used. A drawback of procedural programming is its ability to manage a large interconnecting system.

OOP centers objects in a system. An object has behaviors such as methods and attributes so we can identify them.

Define problems: 
library management: librarian - manage - books and readers who borrows books - the latter three are objects, we name them classes.

## :mag_right: **Classes and Objects**
```python
class ClassName:
    def constructor(self, attribute_value_1, ..., attribute_value_n):
        self.attribute_name_1 = attribute_value_1
        ...
        self.attribute_name_n = attribute_value_n
    def method_name(self, attribute_name_1, ..., attribute_name_m):
        self.method
```
