Why do we Need Numpy?
A list is maily good to store one-dimensional data, but it looks rather confusing representing multi-dimensional data.

Using lists, a few functions can be needed for some purpose when we interact with a list. It's then rather lengthy and time-consuming. This is when numpy arrays come in handy since users can considered a numpy array as one number, which is much easier to handle. Also, `numpy` has built-in functions to perform various operations.

What is a Numpy Array?

A numpy array refers to multi-dimensional data type, often known as ndarry or tensor in Mathematics.

## **Common Methods**

Array Creation

zeros(), ones(), and arange()
arange(start, end, step) - step can be a float.

in regular Python, range(start, end, step) is to make a sequence of equally-spaced numbers, however, step can only be an integer.

reshape() and flatten()

reshape() is to transform the shape of an array, like freezing liquid water to solid

reshape() carries out the operation from left to right and from top to bottom. The number of ways to reshape an array is the number of factors of an array's size.

at least one argument is needed for reshape() and can use any non-negative integer or -1 to let Python compute how many rows/columns for the reshaped array

repeat()

repeat() is to repeat element-wise

if you want to repeat an array like a list, that is, array-wise, we use tile()

you can think of an array as a brick, repeat() means putting bricks on top of each other while tile() means putting bricks next to each other on the same surface.

the argument for axis depends on the shape of an array, specifically cannot exceed the number of axes.
