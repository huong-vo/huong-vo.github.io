## **Random Variable (RV)**
### **Definition** 
Let's use some beginner-friendly scenarios to introduce the idea of a *random variable*. 

| Random Experiment           | Random Variable                                                      | Description | 
|-----------------------------|----------------------------------------------------------------------|-------------|
| Picking a candy from a jar  | The candy color                                                      | If you get red, X = Red. <br> If you get green, X = Green.|
| Spinning a wheel at a fair  | The number of tickets you win                                        | If it lands on "10 tickets", X = 10. <br> If it lands on "good luck next time", X = 0. |
| An entire soccer match      | The number of goals                                                  | If the final score is 2-1, X = 3. |
| Throwing a dart             | The distance from the landing to the bullseye                        | If you hit close, X might be 0.5 inch. <br> If you miss badly, X might be 5 inches. |
| Throwing a dart three times | The number of times the dart lands within 2 inches from the bullseye | If you land within the range once, X = 1. <br> If you lands outside of the range once, X = 4. |

<br>

From above cases, we can think of a *random variable* as a real number depending on the outcome of a random experiment. 

Formally, a **random variable $X$** is a function $X: \Omega \to \mathbb{R}$, $s \mapsto X(s)$ where $\Omega$ is the sample space---set of outcomes and $\mathbb{R}$ is the set of real numbers. Let's delve into two types of random variables and their examples to nail this concept. 

### **Discrete RV - Probability**
A **discrete random variable $X$** is a function $X: \Omega \to \mathbb{R}$ where $\Omega$ is a finite or countably infinite set. Since the range of this function contains numbers representing mutually exclusive events, we can measure *probability on random variables* and the sum of all those must be 1. 

Probability on random variables are known as **probability distribution**. Probability mass and density are common probability distributions.

**Probability Mass Function (PMF)**, denoted by $p(x)$ or $p_X(x)$, measures the probabiltiy of possible values of a discrete random variable, that is, $p(x) = p_X(x) = P(X = x)$. <br>

**Cummulative Distribution Function (CDF)**, denoted by $F(x)$ or $F_X(x)$, is the cumulative probability of of all possible values less than equal to a specific number, that is, $F_X(x) = P(X \le x)$. <br>

### **Continuous RV - Probability**
A **continuous random variable $X$** is a function $X: \Omega \to \mathbb{R}$ where $\Omega$ is an uncountabe set. The *normal distribution* mentioned in [Math for AI 104]({% post_url 2025-07-11-math104 %}) is one of the most well-known probability models for continuous random variables . 

Let's see a couple of examples.
1. Imagine we're looking at the second hand of a clock and take a random snapshot at an unknown moment during a one-minute period. 
    - Define $X(0, 12]$ = angle $\theta$ (in degrees) between the second hand and the 12 o'clock position.
    - The second hand sweeps smoothly in a full circle ($360^\circ$) every minute.
    - So $X \in (0, 360]$. 
2. Adult female/male heights.
    - A person's height can be any positive real number.
    - So $X \in (0, \infty)$.

**PMF for continuous random variables** is *always* 0 since the sample space is so large that it makes the occurence of one value become insignificant. On the other hand, **PDF for continuous random variables** can be computed using the *Gaussian function*.  <br>

## **Mathematical Expectations**
Below are some concepts used for **discrete random variables**. We'll briefly go over mathematical expectations for *continous random variables* right after.

### **Expected Value** 
**Expected value** of a discrete random variable X, denoted by $E[X]$, represents the weighted average value of X and computed as follows. It is often referred to as the mean of probability distribution but tremendously more useful when the size of the sample space is unknown. 

$$E[X] = \sum_{k} x_k \cdot P(X = x_k) = \sum_{k} x_k \cdot p(x_k)$$

Some *important properties* of expected values are 
- $E[\alpha X] = \alpha E[X]$
- $E[\alpha X + b] = \alpha E[X] + b$.

### **Variance**
**Variance** of a random variable X, denoted as $var(X)$, is the weighted average of squared distance from the mean. The reason behind squared distance is that we want to variance to be non-negative for further statistics concepts. On top of that, squared is preferred over absolute value since such a squared function is differentiable everywhere. Use `np.var()`.

$$var(X) = E[(X - \mu)^2] = \sum_{k} (x_k - \mu)^2 p(x_k) = E[X^2] - \mu^2 = E[X^2] - E[X]^2$$

where $\mu = E[X]$.

### **Standard Deviation**
**Standard deviation** of a random variable X, denoted $\sigma(X)$, is the weighted average of distance from the mean. Use `np.std()`.

$$\sigma(X) = \sqrt{var(X)}$$

:pushpin: **Note:** (discussed more in [Math for AI 106]({% post_url 2025-07-18-math106 %}))
1. If outcomes are equally likely to happen and $N$ is the entire population's size, we have 

    $$E[X] = \frac{1}{N} \sum_{k} x_k \text{ and } var(X) = \frac{1}{N} \sum_{k} (x_k - \mu)^2.$$

2. If we only take a sample of size $n$, then N becomes $n - 1$. Add another argument `ddof=1` when using NumPy.

### **Continuous Random Variable**
Since PMFs for continuous random variables are always 0, we can only apply the idea to compute expected value, variance, and standard deviations rather than exactly the same formulas. Here, we use integral for **expected value** which is

$$\mu = E[X] = \int_{-\infty}^{\infty} x f(x) \,dx.$$

This integral can be done using either *Riemann's sum* or *Lebesgue integral* (and maybe other integrals). The former is applied for "nice" distribution while the latter can handle more complicated distributions. This is partly because the Lebesgue integral takes weighted coefficients into account better. *Computers use the Lebesgue integral as its default method.*

## **Covariance and Correlation**
:question: We've been dealing with cases with only one random variable. **What if we'd like to know the relationship between two random variables?**

This is where *covariance* and *correlation* come into play.

### **Covariance** 
**Covariance** measures the *linear relationship* of two random variables, that is, how they change together. Recall $n - 1$ is for samples as we consider $X$ and $Y$ as subset of the population. Use `np.cov()`.

$$cov(X, Y) = E[(X - \mu_X)(Y - \mu_Y)] = \frac{\sum(x - \mu_X)(y - \mu_Y)}{n - 1}$$

where $X$ and $Y$ are random variables such that $E[X] = \mu_X$ and $E[Y] = \mu_Y$.

We deduce from the above formula that $var(X) = cov(X, X)$. *Formally*, **covariance** is represented using the following 2-by-2 matrix 

$$\begin{bmatrix}
var(X) & cov(Y, X) \\
cov(X, Y) & var(Y)
\end{bmatrix}.$$

We can interpret the result as follows.
- $cov(X, Y) \in (-\infty, \infty)$.
- $cov(X, Y) = cov(Y, X)$.
- If it is positive covariance or $cov(X, Y) > 0$, then $X$ *increases* implies $Y$'s *rise* on average.
- If it is negative covariance or $cov(X, Y) < 0$, then $X$ *reduces* implies $Y$'s *decrease* on average.
- If it is zero covariance or $cov(X, Y) = 0$, then there is *no* linear correlation between two random variables.

### **Correlation**
Even though covariance is useful, its value can be unnecessarily large. In addition, covariance only indicates the direction of the relationship, *not* how much it is. To address this issue, we standardize the covariance to obtain the **correlation coefficient**.

**Correlation** is a statistical measure the quantifies the strength and direction of a *linear relationship* between two random variables. Use `np.corrcoef()`.

$$
\begin{align*}
corr(X, Y) & = \frac{cov(X, Y)}{\sigma_X \cdot \sigma_Y} = \frac{cov(X, Y)}{\sqrt{var(X)} \cdot \sqrt{var(Y)}} \\
           & = \frac{n (\sum_{i} x_i y_i) - (\sum_i x_i) (\sum_i y_i)}{\sqrt{n (\sum_{i} x_i^2) - (\sum_{i} x_i)^2} \cdot \sqrt{n (\sum_{i} y_i^2) - (\sum_{i} y_i)^2}}
\end{align*}
$$

It is also often represented as a 2-by-2 matrix like covariance. 

$$\begin{equation*}
\begin{bmatrix}
corr(X, X) & corr(Y, X) \\
corr(X, Y) & corr(Y, Y)
\end{bmatrix}
=
\begin{bmatrix}
1 & corr(Y, X) \\
corr(X, Y) & 1
\end{bmatrix}
\end{equation*}
$$

We can interpret the result as follows.
- $corr(X, Y) \in [-1, 1]$.
- $corr(X, Y) = corr(Y, X)$.
- If it is positive correlation or $corr(X, Y) > 0$, then $X$ increases implies $Y$'s rise on average.
    - If $corr(X, Y) = 1$, values of $X$ and $Y$ form a straight line with a positive slope.
    - If $corr(X, Y)$ is close to 1, then it is a strong relationship and values of $X$ and $Y$ lie close to a straight line.
    - If $corr(X, Y)$ is not so close to 1, then it is a weaker relationship and values of $X$ and $Y$ are distributed around but further away from a straight line.
- If it is negative covariance or $corr(X, Y) < 0$, then $X$ reduces implies $Y$'s decrease on average.
    - If $corr(X, Y) = -1$, values of $X$ and $Y$ form a straight line with a negative slope.
    - If $corr(X, Y)$ is close to -1, then it is a strong relationship and values of $X$ and $Y$ lie close to a straight line.
    - If $corr(X, Y)$ is not so close to -1, then it is a weaker relationship and values of $X$ and $Y$ are distributed around but further away from a straight line.
- If it is zero covariance or $corr(X, Y) = 0$, then there is no linear relationship between two random variables and values scatter without a clear linear pattern.

### **Continuous Random Variable**
Like mathematical expectations, we *cannot* directly compute covariance and correlation of continuous random variables. In this case, we can convert continous random variables to discrete ones using **Monte Carlo method**. Softwares may have it set up in methods as follows.

```python
# X ~ N(0, 1) 
# Y ~ N(0.5, 1.5)
data1 = np.random.normal(0, 1, 1000)
data2 = np.random.normal(0.5, 1.5, 1000)

# calculate covariance and correlation matrix
covariance_matrix = np.cov(data1, data2)
correlation_matrix = np.corrcoef(data1, data2)
```

## :speech_balloon: **FAQ**
Here are some good questions asked during class. The answers to these questions came from either some admin, TA, STA, or members of AIO2025.

| Questions | Answers |
|-----------|---------|
| Are there any cases where continuous random variables are converted to discrete random variables for easier computations? | Yes. We can use **Monte Carlo method** to make it happen. We divide uncountable values into bins/classes/intervals which are considered single values, then use naive Bayes or histogram. For example, salaries can be categorized into groups like low, medium, and high. |
| Resources for Applied Statistics | [Storytelling with Data: A Data Visualization Guide for Business Professionals](https://www.google.com/books/edition/Storytelling_with_Data/rRSRCgAAQBAJ?hl=en&gbpv=0) by Cole Nussbaumer Knaflic, [Statistics: The Art and Science of Learning from Data](https://www.amazon.com/Statistics-Science-Learning-Books-Carte/dp/0133860825) by Alan Agresti, [Introduction to Probability](https://www.amazon.com/Introduction-Probability-Chapman-Statistical-Science/dp/1138369918) by Blitzstein |
| How do Riemman and Lebesgue integrals work? | Riemman integral is like accounting, accummulating bit by bit. Lebesgue integral is like a cashier taking money, putting money into their own category and summing them up in the end. |
| Why n - 1 for sample? | This is called Bessel's correction in Statistics. When using sample, selected value points tend to lie closer to the sample mean than the population mean. Thus, using n makes values' distribution (variance/standard deviation) is lower than what it really is. Taking n - 1 is a way to make up for it to address bias, helping the result reflect the distribution of the population better. When writing code, use `ddof = 1` for variance and standard deviation computations.|
| How are these expectations used in Machine Learning? | They can be used in optimization problems. In some cases, models need to take actions that maximize expectations in game theory. Basically, "learning" in Machine Learning is to find models so that average expectation errors are the least insignificant. |
