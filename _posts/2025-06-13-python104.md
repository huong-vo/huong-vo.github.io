### :bricks: **Review: Data Structure and List** 
Data structure is a format for storing, organizing, and manipulating data efficiently. Like how your things are organized at home, for example, if your books are all over the place, it may take forever to find one when needed. But if they are placed on the shelves in an orderly fashion, you can quickly locate the one you want in a second.

Data structures fall into two main categories: built-in and user-defined. We'll focus our attention on the former. We'll learn more about the latter and how to create one later in this **Python for AI** series. 

A list can be one-dimensional, two-dimensional, and multi-dimensional. We talked about the first two with 2D lists being one list nesting another. You can think of these lists as a matrix, or imagine them as desks arranged in rows and columns, like in a classroom.

## :mag_right: **Mutable vs Immuatable**
**Objects** are the building blocks of Python, representing everything in the language. Each object has 3 unique properties:
- Identity: the memory address of an object, like key in dictionary.
- Type: the data representation of an object, like integer, string, boolean, or list.
- Value: the value assigned an object, like value in dictionary.

While identity and type cannot be changed after creation of an object, values inside can be either changeable or not. The mutability of object types refers to this behavior. Note that reassignment (i.e., assigning an entire object to something else or some other value) is completely different from mutability. 

|   | Mutable    | Immutable |
|---|:----------:|:------------:|
| Properties | can change the value of elements after the assignment without changing where it is in memory | cannot change the value of elements after assignment whatsoever |
| Data Structures | list, dictionary, set | string, tuple |
| Examples | list | Tree         |
| Set        | Graph        |
|            | Linked List  |
