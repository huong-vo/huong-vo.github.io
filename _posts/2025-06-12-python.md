## :mag_right: **Data Representation**
In Python, data can be represented in various ways which are sorted into three groups discussed below. To work with data in any programming language, it is imperative that it be stored to a **variable**. That way, you can refer to and work with such a variable later on. In Python, the syntax to define a variable is simple.
```python
variable_name = variable_value
```
You may want to think of a variable as a container, a variable name as the container's name, and a variable value as what is inside that container. You are allowed to use and/or modify the value as needed. For instance, `mystery_box = "IPhone"` means a container called `mystery_box` has a value of `"IPhone"` in it. 

Now, you may ask: **What can I can name a variable? Are there any conventions I should be aware of?** A few thing is worth mentioning regarding the varibale name.
- **Meaningful name:** Even though you can name a variable whatever you want, it makes sense to give a name relevant to its purpose.
- **snake_case:**
- **Avoid [keyword](https://realpython.com/python-keywords/):** A syntax error is returned as a keyword is used as a variable. Usually, the editor you use displays a red squiggly underline under such a variable name.

##### :heavy_exclamation_mark: **Overflow and Underflow**
No matter how much a language's memory is extended, their size is always limited or blocked on both sides. This means a computer's memory cannot represent too large or too small numbers. These situations are called overflow and underflow, respectively. Python returns *inf* for the former and *0.0* for the latter.

As you may know, a computer can *only* understand numbers, therefore, it is a must to convert texts into numbers so that the computer system and network can tackle. This is a common **NLP** task; an example that you may know is [Google Translate](https://translate.google.com/?sl=auto&tl=fr&op=translate).

### :two: **More Abstract Data Structure**
Just as their name suggest, primitive data representation can only support basic jobs. To handle more complex assignment, we need (built-in) multiplex structures such as list and dictionary. Here, we'll just get to know their definitions and discuss them in detail in []().

#### :heavy_check_mark: **List**
```python
list_name = [element_1, ..., element_n]
```
In addition to their values, each element is associated to an index which is automatically created when the list is defined. Forward indices start at 0 for the first element on the left and increase one by one till the end of the list. In practice, you get to elements' values via their indices. Let's take a look at an example. 
```python
    # create a list of fruits
    fruits = ["apple", "orange", "banana", "grapes", "mango"]

    fruits[0]
    >>> "apple"
    fruits[2]
    >>> "banana"
```

Of course, elements of a list can be logic, numbers, and more.
```python
    data = [5, 4.7, -2, "hello", 0, True, -1000.1]
```

#### :heavy_check_mark: **Dictionary**
```python
dictionary_name = {key_1: value_1, ..., key_n: value_n}
```
Another prevalent data structure is dictionary. When you look up a word in a regular-sense dictionary, you'll see two parts: the word and its meaning(s); no word appears more than once in a dictionary. A dictionary in Python is created in a similar fashion with unique keys and a value for each of them. Take the following example.
```python
# create a dictionary of a fruit's characteristics
fruit = {"name": "avocado", "type": "berry", "nutrition": ["fat", "fiber", "vitamins"], 7: 100}

fruit[7]
>>> 100
fruit["nutrition"]
>>> ["fat", "fiber", "vitamins"]
```
As seen above, in a dictionary, an element's value can be retrieved using its key in lieu of index.

### :heavy_check_mark: **Types of Functions**
There are two main types of functions including built-in functions and user-defined functions.

#### :one: **Built-in Funtions**
Built-in functions are created by and freely available to the Python community. Two common built-in functions are `print` and `type`. The former displays output and the latter returns the type of a given variable. 

Besides functions used without further concerns, there are functions that can only be executed with packages called **module** like `random` and `math`. Use the `import` keyword to access modules. Try and see what the code below gives you. 
```python
import math

x = 4
y = -3

print(math.sqrt(x))
print(math.sqrt(y))
print(math.fabs(x))
print(math.fabs(y))
print(math.log(math.e))  # log is based e
```

:heavy_check_mark: **Logarithm Function** 
<br>
:abacus: Logarithm has $\log({1}) = 0$ and is a monotonically increasing function, i.e., $f(x_1) < f(x_2) \text{ when } x_1 < x_2$. 

These properties extensively used in **optimization algorithms** problems which are ubiquitous in **machine learning**. For example, in a situation where we maximize a function, evaluating *log* of the function is computationally easier than the function itself while taking its *log* does not change the maximum's position.

:one: **When do I use the *log* function?** 
<br>
The short answer is when you only care about the value of a number compared to that of another rather than their actual values. Since *log* of a number approaches $\infty$ and $-\infty$ much more slowly than the number goes to $\infty$ and $0$, respectively, the program can easily avoid the **overflow and underflow** issues.
